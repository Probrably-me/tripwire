Planned detections

Six checks for the first release. The list will change as testing goes on.

Planned Tripwire detections
KillauraFlags attacks outside the field of view and impossible rotations. Checks the attack rate per tick.
FlyCompares vertical movement against the vanilla movement model (gravity, drag). Detects staying airborne without support.
SpeedCaps horizontal speed by block, potion effects and player state (sprint, sneak, ice).
ReachMeasures the distance from the player's eye to the targeted hitbox, with latency compensation.
NoFallChecks that the on-ground flag sent by the client matches the real position.
TimerDetects a movement packet rate above 20 per second over time.

Technical

Design targets. Measurements will come with the testing phase.

Compatibility
Paper and Spigot 1.21.11. Java 21 required.
Interception
Reads incoming packets before the server processes them.
Execution
Async checks, off the main thread. Punishments are applied on the next tick.
TPS impact
Target: under 2% extra MSPT at 100 players.
Configuration
One YAML file per check. Thresholds and punishments are adjustable.
Data
No telemetry, no outbound network requests.
